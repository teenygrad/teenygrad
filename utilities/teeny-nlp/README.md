# teeny-nlp

Text-processing/tokenizer utilities for [teenygrad](https://teenygrad.org), built on
`fancy-regex`, `regex`, and `bstr`.

## Prerequisites

- **Rust**: any stable or nightly toolchain. No system-library or custom-compiler dependencies.

## Getting started

```toml
[dependencies]
teeny-nlp = "0"
```

See the `tokenizer` module for the available APIs.
